# Dana Theron — Automation Portfolio

Static portfolio website prepared for Cloudflare Pages.

## Deploy with Cloudflare Pages

1. Push this folder to a GitHub repository.
2. In Cloudflare, open **Workers & Pages** and create a Pages project.
3. Connect the GitHub repository.
4. Leave the build command empty.
5. Set the output directory to `/`.
6. Deploy.

Cloudflare will provide a `pages.dev` address and automatically redeploy future Git pushes.

## Before public promotion

- Connect the enquiry form to a form service or Pages Function.
- Add a real GitHub/profile link when available.
- Add a custom domain when ready.
